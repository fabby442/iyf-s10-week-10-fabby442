## Project Description
This project is a backend API built using Node.js and Express. It demonstrates REST API development, middleware usage, error handling, modular architecture, and environment variables.

## Technologies Used
- Node.js
- Express.js
- JavaScript (ES6)
- REST API
- dotenv
- Git & GitHub

## Features
- Full CRUD API for posts
- Middleware (logger, authentication, validation)
- Error handling system
- Query filtering (author, sort)
- Route parameters and query strings
- Modular folder structure
- Environment variables support
